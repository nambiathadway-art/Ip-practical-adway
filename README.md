# Introduction to Programming (VBCS1101) - Practical Codes

Python solutions for Practicals 1-12 (BSc CS AIML, Sem I).

## How to run
```
python practical_03_conditionals.py
```
A menu lists every question. Type `q3` for question 3, `pq2` for practice question 2
(`s1`-`s8` in Practical 7 are the 2D indexing/slicing questions), `x` to exit.
Practical 6 and 7 need NumPy: `pip install numpy`.

| File | Topic |
|---|---|
| practical_01_variables.py | Variables, constants, data types |
| practical_02_io_arithmetic.py | Input/output, arithmetic expressions |
| practical_03_conditionals.py | if / elif / else, nested if |
| practical_04_loops.py | for, while, nested loops |
| practical_05_loop_control.py | break, continue, pass |
| practical_06_arrays.py | 2D lists and NumPy arrays |
| practical_07_lists_tuples.py | Lists, tuples, 2D slicing |
| practical_08_dictionaries.py | Dictionaries |
| practical_09_functions.py | Functions and recursion |
| practical_10_strings.py | Strings |
| practical_11_file_handling.py | Text files |
| practical_12_exceptions.py | Exception handling |
